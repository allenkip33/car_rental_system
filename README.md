# Car Rental Management System

This is a Python project for managing cars, users and rentals.

## Features

* Register and login users
* Add and view cars
* Rent and cancel cars
* Manage rental information
* Store data using JSON files


## How to Run

Install the requirements:
 
```bash
pip instll -r requirements.txt
```

Run the program:

```bash
python main.py
```

## Testing

Run the tests with=

```bash
pytest
```
